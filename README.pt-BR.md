# expr-eval-core

Avaliador de expressões aritméticas: parser Pratt, precedência,
variáveis, funções matemáticas. Zero dependências, Node >= 22.

Parte do laboratório open source da LOFRANO TECNOLOGIA. MIT.

```sh
npm test          # 6 testes, node:test, sem dependências
npm run demo
```

Só números entram e saem; `&&`/`||` com curto-circuito. MIT — veja `LICENSE`.
